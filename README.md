# Parag Gulati — Backend Engineer Portfolio

A fast, static portfolio and ATS-friendly résumé for Parag Gulati. The site highlights five engineering projects from his work at MultiTV Tech Solutions: Kutingg, Momentus, Media-Morph, Art of Living, and Law & Crime.

**Live site:** https://parag9990.github.io/ParagPortfolio/

## Preview locally

From the repository root:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. No build step or dependencies are required.

## GitHub Pages publishing

The repository publishes from the `main` branch, `/(root)` folder. Pushes to `main` update the live site automatically.

## Edit content

- `index.html` — portfolio copy and case studies
- `styles.css` — visual design and responsive layout
- `resume.html` — accessible, print-friendly résumé
- `Parag-Gulati-Backend-Engineer-Resume.pdf` — downloadable, selectable-text résumé
- `parag-gulati-avatar.png` — portrait from Parag's public GitHub profile
- `social-preview.jpg` — social sharing preview image
- `sitemap.xml` and `robots.txt` — search discovery files

Project facts and metrics are based on the résumé supplied by Parag. The case studies describe his contributions rather than claiming ownership of entire products.
